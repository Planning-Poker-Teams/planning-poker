= Running Terraform Locally

This guide creates a personal cloud environment in AWS. It is not the true offline or localhost development flow.

For a local websocket backend using MiniStack, see link:local-backend.adoc[Local backend].

== Init
[source]
----
AWS_PROFILE=planning-poker \
  tfenv exec init \
  -backend-config=region=eu-central-1 \
  -backend-config=bucket=estim8-deploy-state \
  -backend-config=dynamodb_table=estim8-deploy-state-locks \
  -backend-config=key=${USER}-local.tfstate
----

== Apply
[source]
----
AWS_PROFILE=planning-poker \
  tfenv exec apply
----
